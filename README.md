# Agentic AI Book

A practical, example-driven course repository for learning Agentic AI, large language models, prompt engineering, tool use, retrieval-augmented generation (RAG), and agent workflows.

This project contains:
- HTML-based course material for a 24-day learning path
- Practice notebooks and Python examples
- Demo code for ML/LLM workflows and agentic patterns
- A structured curriculum focused on building hands-on AI skills

## Course Highlights

- Foundations of AI, ML, deep learning, and LLMs
- Python essentials for AI and data processing
- Prompt engineering and hallucination mitigation
- Tool calling and agent behavior
- Retrieval-augmented generation (RAG)
- Workflow design and multi-step AI systems
- LangGraph, automation, and production-style agent design

## How to Use This Repository

### 1. Open the course material
The main course landing page is in:

- `Material/index.html`

Open it in a browser to browse the lessons and exercises.

### 2. Explore practice work
The `Practice/` folder contains notebooks and examples for hands-on learning.

### 3. Read the curriculum plan
The file `agentic_ai_course_plan.md` contains the structured day-by-day plan used to build the course materials.

## Prerequisites

- Python 3.9+
- Jupyter Notebook or VS Code with Python support
- Internet access for package installation and API demos
- Optional: OpenAI or other model provider API keys for exercises using LLM APIs

## Suggested Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install jupyter notebook
```
