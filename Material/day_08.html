8.1. Problem Solver Cognitive Architecture

Real-world engineering challenges (e.g., enterprise cloud migration ROI modeling, complex tax reconciliations, or diagnosing distributed microservice failures) cannot be solved by single-turn LLM generation. Attempting a one-shot response inevitably leads to calculation drift, overlooked constraints, and unformatted outputs.

The Autonomous Problem Solver implements a rigorous 4-stage cognitive lifecycle with isolated responsibility boundaries:

[STAGE 1: PLANNER & DECOMPOSER]
• Ingests ambiguous problem string.
• Generates typed SolutionPlan with ordered ProblemStep objects, tool bindings, and expected outputs.
[STAGE 2: DISPATCHER & EXECUTION ENGINE]
• Iterates over steps in topological order.
• Routes deterministic tasks to verified local tools (Math, Regex, Code Sandbox).
• Routes semantic tasks to specialized LLM agents.
[STAGE 3: ADVERSARIAL VALIDATION GATE]
• Pydantic assertions + Adversarial Critic prompt inspect output consistency.
• If step fails, triggers targeted reflection retry (max 3 attempts).
[STAGE 4: SYNTHESIS & AUDIT EXPORTER]
• Compiles verified execution history into executive Markdown dossier.
• Exports immutable JSON audit artifact with timestamps and token metrics.

8.2. Program 1: The Core Autonomous Problem Solver Engine

The complete, typed Python implementation below incorporates Pydantic v2 schemas, tool routing, an adversarial validation gate, and comprehensive error handling:

program_8_1_problem_solver_core.py 

# Program 8.0-1: Autonomous Problem Solver Engine
import json
import math
import re
import time
from typing import List, Optional, Literal, Dict, Any
from pydantic import BaseModel, Field
from openai import OpenAI

client = OpenAI()

# =====================================================================
# 1. TYPE CONTRACTS & SCHEMAS
# =====================================================================
class ProblemStep(BaseModel):
    step_number: int
    title: str = Field(description="Short title of the sub-task")
    description: str = Field(description="Precise, actionable instructions")
    tool_needed: Literal["calculator", "regex_extractor", "code_executor", "none"] = Field(
        description="Select calculator for math, regex for structured tokens, code_executor for algorithms, or none"
    )

class SolutionPlan(BaseModel):
    problem_category: Literal["financial_analysis", "technical_troubleshooting", "data_extraction", "system_sizing", "general"]
    complexity: Literal["low", "medium", "high"]
    confidence: float = Field(ge=0.0, le=1.0)
    steps: List[ProblemStep]

class ValidationResult(BaseModel):
    passed: bool
    confidence_score: float = Field(ge=0.0, le=1.0)
    identified_errors: List[str] = Field(default_factory=list)
    suggested_correction: Optional[str] = None

# =====================================================================
# 2. DETERMINISTIC LOCAL TOOLS
# =====================================================================
def safe_calculator(expression: str) -> str:
    """Safely evaluates algebraic expressions without code injection risk."""
    try:
        sanitized = re.sub(r"[^0-9\+\-\*\/\.\(\)\s\^]", "", expression).replace("^", "**")
        allowed_names = {"sqrt": math.sqrt, "pow": math.pow, "abs": abs, "round": round}
        val = eval(sanitized, {"__builtins__": None}, allowed_names)
        return json.dumps({"status": "success", "result": round(float(val), 4)})
    except Exception as e:
        return json.dumps({"status": "error", "message": f"Calculation error: {str(e)}"})

def regex_extractor(pattern: str, text: str) -> str:
    """Extracts pattern matches deterministically."""
    try:
        matches = re.findall(pattern, text)
        return json.dumps({"status": "success", "matches": matches})
    except Exception as e:
        return json.dumps({"status": "error", "message": f"Regex compilation error: {str(e)}"})

# =====================================================================
# 3. PIPELINE STAGE FUNCTIONS
# =====================================================================
def stage1_planner(problem_statement: str) -> SolutionPlan:
    """Stage 1: Deconstructs the problem into an ordered, verified SolutionPlan."""
    completion = client.beta.chat.completions.parse(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You are a Principal Solutions Architect. Deconstruct ambiguous problems into strictly ordered, verifiable sub-steps."},
            {"role": "user", "content": f"Deconstruct this problem statement:\n{problem_statement}"}
        ],
        response_format=SolutionPlan,
        temperature=0.0
    )
    return completion.choices[0].message.parsed

def stage2_execute_step(step: ProblemStep, accumulated_context: Dict[str, Any]) -> str:
    """Stage 2: Dispatches the step to either a local deterministic tool or specialized LLM."""
    if step.tool_needed == "calculator":
        extract_prompt = f"""
        Given the problem context: {json.dumps(accumulated_context)}
        Extract ONLY the raw mathematical formula for: '{step.description}'.
        Return nothing except the mathematical expression (e.g., (85000 * 0.88) * 1.18).
        """
        expr_res = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": extract_prompt}],
            temperature=0.0
        )
        formula = expr_res.choices[0].message.content.strip().replace("`", "")
        print(f"    [Tool: Calculator] Formula: {formula}")
        return safe_calculator(formula)

    # General reasoning specialist
    prompt = f"""
    Context So Far:
    {json.dumps(accumulated_context, indent=2)}
    
    Current Goal:
    {step.title}: {step.description}
    
    Produce a concise, factual, and direct resolution for this specific step.
    """
    res = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.2
    )
    return res.choices[0].message.content

def stage3_validate_step(step: ProblemStep, step_result: str, accumulated_context: Dict[str, Any]) -> ValidationResult:
    """Stage 3: Adversarial validation gate checking for hallucinations or math inconsistencies."""
    eval_prompt = f"""
    You are an Adversarial Quality Assurance Inspector.
    Audit whether the produced Step Result completely satisfies the Step Description without error.
    
    Step Description: {step.description}
    Tool Used: {step.tool_needed}
    Step Result: {step_result}
    Context: {json.dumps(accumulated_context)}
    
    Flag any inconsistencies, division-by-zero risks, or numerical hallucinations.
    """
    completion = client.beta.chat.completions.parse(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": eval_prompt}],
        response_format=ValidationResult,
        temperature=0.0
    )
    return completion.choices[0].message.parsed

def stage4_synthesize_report(problem: str, plan: SolutionPlan, step_history: List[Dict[str, Any]]) -> str:
    """Stage 4: Synthesizes final verified executive dossier in GitHub-flavored Markdown."""
    prompt = f"""
    You are an Executive Technology Director. Synthesize a final resolution report in Markdown.
    
    Original Problem Statement:
    "{problem}"
    
    Classification: {plan.problem_category} (Complexity: {plan.complexity})
    Verified Execution Log:
    {json.dumps(step_history, indent=2)}
    
    Report Requirements:
    1. Executive Summary
    2. Numerical Reconciliation Table
    3. Step-by-Step Findings
    4. Strategic Recommendations
    """
    res = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.2
    )
    return res.choices[0].message.content

# =====================================================================
# 4. ORCHESTRATOR LOOP
# =====================================================================
def run_autonomous_solver(problem_statement: str) -> Dict[str, Any]:
    print("=" * 65)
    print(f"INGESTING PROBLEM:\n'{problem_statement}'")
    print("=" * 65)
    
    # 1. Plan
    print("\n--> [Stage 1] Generating Structured Solution Plan...")
    plan = stage1_planner(problem_statement)
    print(f"    Category: {plan.problem_category.upper()} | Complexity: {plan.complexity.upper()} | Steps: {len(plan.steps)}")
    
    context: Dict[str, Any] = {"original_problem": problem_statement}
    execution_history: List[Dict[str, Any]] = []
    
    # 2. Iterate Steps
    for step in plan.steps:
        print(f"\n--> [Step {step.step_number}/{len(plan.steps)}] {step.title} (Tool: {step.tool_needed})")
        passed = False
        attempts = 0
        max_retries = 3
        current_result = ""
        
        while not passed and attempts < max_retries:
            attempts += 1
            current_result = stage2_execute_step(step, context)
            val = stage3_validate_step(step, current_result, context)
            
            if val.passed:
                passed = True
                print(f"    ✓ Validation Passed (Attempt {attempts}) [Confidence: {val.confidence_score:.2f}]")
            else:
                print(f"    ✗ Gate Warning (Attempt {attempts}): {val.identified_errors}")
                context["last_error"] = val.identified_errors
                context["suggested_fix"] = val.suggested_correction
        
        context[f"step_{step.step_number}_result"] = current_result
        execution_history.append({
            "step": step.step_number,
            "title": step.title,
            "tool": step.tool_needed,
            "result": current_result,
            "attempts": attempts
        })

    # 3. Final Synthesis
    print("\n--> [Stage 4] Generating Final Executive Report...")
    final_report = stage4_synthesize_report(problem_statement, plan, execution_history)
    
    return {
        "plan": plan.model_dump(),
        "history": execution_history,
        "final_report": final_report
    }

if __name__ == "__main__":
    challenge = (
        "We are migrating 14 legacy on-premise servers consuming 42,000 kWh annually at ₹9.50 per kWh. "
        "The cloud equivalent costs $480 USD/month (exchange rate 1 USD = 83.50 INR). "
        "Hardware maintenance on-premise costs ₹1,20,000/year. "
        "Calculate our total annual cost for both options, net annual savings in INR, and ROI percentage."
    )
    result = run_autonomous_solver(challenge)
    print("\n" + "=" * 30 + " EXECUTIVE DOSSIER " + "=" * 30)
    print(result["final_report"])

8.3. Program 2: Interactive Terminal UI with Rich & Human-in-the-Loop (HITL)

Enterprise users require visibility, live step spinners, and the power to inspect or modify the generated execution plan before any external tools run. Below is the production CLI interface utilizing rich and an interactive Human-in-the-Loop approval gate:

program_8_2_rich_cli_hitl.py 

# Program 8.0-2: Rich Interactive Terminal UI with Human-in-the-Loop Approval
from typing import List
from rich.console import Console
from rich.table import Table
from rich.panel import Panel
from rich.progress import Progress, SpinnerColumn, TextColumn
from rich.prompt import Prompt, Confirm
from pydantic import BaseModel, Field
from openai import OpenAI

console = Console()
client = OpenAI()

class ProblemStep(BaseModel):
    step_number: int
    title: str
    tool_needed: str
    description: str

class PlanModel(BaseModel):
    summary: str
    steps: List[ProblemStep]

def render_plan_table(plan: PlanModel):
    """Renders a beautiful Rich table displaying the generated decomposition."""
    table = Table(title="[bold cyan]Decomposed Execution Plan[/bold cyan]", show_header=True, header_style="bold magenta")
    table.add_column("Step", style="dim", width=6)
    table.add_column("Title", style="bold white", width=25)
    table.add_column("Tool", style="green", width=15)
    table.add_column("Instruction", style="yellow")
    
    for s in plan.steps:
        table.add_row(str(s.step_number), s.title, s.tool_needed, s.description)
    
    console.print(table)

def interactive_hitl_planner(problem: str) -> PlanModel:
    """Generates plan and pauses for Human-in-the-Loop approval or revision."""
    with Progress(
        SpinnerColumn(spinner_name="dots"),
        TextColumn("[progress.description]{task.description}"),
        transient=True
    ) as progress:
        progress.add_task(description="Decomposing problem statement...", total=None)
        comp = client.beta.chat.completions.parse(
            model="gpt-4o-mini",
            messages=[
                {"role": "system", "content": "Decompose the user problem into numbered steps with appropriate tools."},
                {"role": "user", "content": problem}
            ],
            response_format=PlanModel
        )
        plan = comp.choices[0].message.parsed

    console.print(Panel(f"[bold green]Problem Statement:[/bold green] {problem}", title="Ingestion"))
    render_plan_table(plan)

    # Human-in-the-Loop Approval Gate
    approved = Confirm.ask("\n[bold yellow]Do you approve this execution plan?[/bold yellow]", default=True)
    
    if not approved:
        feedback = Prompt.ask("[bold red]Enter your instructions for plan revision[/bold red]")
        console.print("[cyan]Regenerating plan with human feedback...[/cyan]")
        comp = client.beta.chat.completions.parse(
            model="gpt-4o",
            messages=[
                {"role": "system", "content": "Revise the plan strictly incorporating user feedback."},
                {"role": "user", "content": f"Problem: {problem}\nPrior Plan: {plan.model_dump_json()}\nUser Feedback: {feedback}"}
            ],
            response_format=PlanModel
        )
        plan = comp.choices[0].message.parsed
        console.print("[bold green]✓ Plan revised successfully![/bold green]")
        render_plan_table(plan)
        
    return plan

if __name__ == "__main__":
    console.clear()
    sample_query = "Calculate annual depreciation of a 25 Lakh INR manufacturing robot over 7 years using Straight-Line and WDV (15%) methods."
    final_approved_plan = interactive_hitl_planner(sample_query)
    console.print("[bold green]Execution authorized. Handing off to dynamic dispatcher...[/bold green]")

8.4. Program 3: Sandboxed Code Runner with Self-Healing Error Loop

Certain problem steps require running custom Python scripts to parse complex datasets or calculate multi-variable formulas. The sandboxed code runner executes code in an isolated sub-process with memory and timeout constraints, capturing stderr and invoking self-healing reflection if runtime errors occur:

program_8_3_sandboxed_executor.py 

# Program 8.0-3: Sandboxed Code Runner with Autonomous Self-Healing Reflection Loop
import subprocess
import tempfile
import os
import sys
from typing import Dict, Any
from openai import OpenAI

client = OpenAI()

def execute_sandboxed_python(code: str, timeout_seconds: int = 5) -> Dict[str, Any]:
    """Executes Python code in an isolated subprocess with timeout constraints."""
    with tempfile.NamedTemporaryFile("w", suffix=".py", delete=False) as f:
        f.write(code)
        temp_path = f.name

    try:
        proc = subprocess.run(
            [sys.executable, temp_path],
            capture_output=True,
            text=True,
            timeout=timeout_seconds
        )
        return {
            "success": proc.returncode == 0,
            "stdout": proc.stdout.strip(),
            "stderr": proc.stderr.strip(),
            "returncode": proc.returncode
        }
    except subprocess.TimeoutExpired:
        return {
            "success": False,
            "stdout": "",
            "stderr": f"Execution timed out after {timeout_seconds}s (infinite loop guard triggered).",
            "returncode": -1
        }
    finally:
        if os.path.exists(temp_path):
            os.remove(temp_path)

def generate_and_execute_with_self_healing(task_description: str, max_healing_attempts: int = 3) -> str:
    """Generates Python code to solve a task, automatically healing runtime bugs."""
    messages = [
        {"role": "system", "content": "You are an expert Python engineer. Write standalone, executable Python script that prints the final answer."},
        {"role": "user", "content": f"Task: {task_description}"}
    ]

    for attempt in range(1, max_healing_attempts + 1):
        print(f"--> [Self-Healing Sandbox] Generation Attempt {attempt}/{max_healing_attempts}...")
        res = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages,
            temperature=0.0
        )
        raw_code = res.choices[0].message.content
        
        # Clean markdown code fences
        clean_code = raw_code.replace("```python", "").replace("```", "").strip()
        
        # Execute in sandbox
        exec_res = execute_sandboxed_python(clean_code)
        
        if exec_res["success"]:
            print(f"    ✓ Execution succeeded on attempt {attempt}!")
            return exec_res["stdout"]
        else:
            print(f"    ✗ Runtime Error encountered on attempt {attempt}:")
            print(f"       {exec_res['stderr'][:150]}...")
            
            # Feed the exact stack trace back into LLM context for self-correction
            messages.append({"role": "assistant", "content": raw_code})
            messages.append({
                "role": "user",
                "content": f"Code execution failed with error:\n{exec_res['stderr']}\nPlease fix the bug and return only the corrected script."
            })

    raise RuntimeError(f"Failed to execute code successfully after {max_healing_attempts} self-healing iterations.")

if __name__ == "__main__":
    test_task = (
        "Generate 10,000 synthetic numbers from a normal distribution with mean 100 and stddev 15. "
        "Calculate the 99th percentile and print only the result rounded to 2 decimal places."
    )
    result = generate_and_execute_with_self_healing(test_task)
    print(f"\nFinal Verified Sandboxed Output:\n{result}")

8.5. Production Failure Modes & Hardening Playbooks

  • 1. Subprocess Code Injection & Escape: Allowing the LLM to write arbitrary code executed via subprocess or eval can allow malicious prompts to delete local files or leak environment secrets. Hardening: Run user-generated code inside unprivileged Docker containers or gVisor/Firecracker microVMs without network access, using dedicated read-only filesystem mounts.
  • 2. Decomposition Hallucination: Planners may decompose a simple task into 25 unnecessary steps, ballooning token costs and latency. Hardening: Enforce Pydantic Field(max_length=8) on the step list, constraining the planner to 8 discrete steps maximum.
  • 3. Partial Step State Desynchronization: If step 3 relies on a variable named total_tax from step 2, but step 2's output named it tax_amount, step 3 fails. Hardening: Standardize intermediate state keys through strict Pydantic dictionaries rather than relying on ungrounded text parsing.
  • 4. Silent Validation Leniency: If the validation prompt is too agreeable (a common LLM bias), it will approve flawed results. Hardening: Frame the validator adversarially ("You are an Auditor penalized for approving flawed calculations. Actively seek discrepancies.") and use temperature 0.0.
