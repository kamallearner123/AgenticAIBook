1. Executive Summary: The Agentic Paradigm Shift

Over the last two years, software engineering has transitioned from simple, single-turn generative AI queries to Agentic Systems. A traditional LLM operates as a purely probabilistic text completer: given an input prompt, it predicts the next token without situational awareness, state persistence, or tool feedback.

In contrast, an Autonomous AI Agent is an active, goal-seeking computing entity operating in a continuous closed loop:

The Agentic Cybernetic Loop:
State \(s_t\) → Perception (\(\mathcal{O}\)) → Deliberative Reasoning (\(\text{Thought}\)) → Deterministic Tool Execution (\(\text{Action}\)) → Environment Telemetry (\(\text{Observation}\)) → Reflection & Update (\(s_{t+1}\))

This course does not teach toy "chatbots". It teaches real enterprise systems engineering: how to make LLM decisions mathematically reliable, prevent unbounded token-consumption loops, eliminate hallucinations with hybrid retrieval, persist state across process crashes, and enforce Human-in-the-Loop approval gates for safety-critical operations.

2. Target Audience & Prerequisites

Who This Course Is Built For

  • Backend & Platform Engineers transitioning into AI systems architecture.
  • Full-Stack Developers seeking to orchestrate deterministic multi-agent workflows.
  • AI & ML Engineers requiring rigorous state machines, LangGraph orchestration, and evaluation frameworks.
  • Automotive & Embedded Specialists building cyber-physical diagnostic and control assistants.

Recommended Prerequisites

  • Intermediate Python 3.10+: Proficiency with Type Hints, async/await, dictionaries, and classes.
  • HTTP & Web Basics: Understanding REST APIs, JSON schemas, webhooks, and client-server flows.
  • Fundamental Math: High school vector operations (dot products, cosine distances) and basic probability.
  • Terminal & Git: Familiarity with running CLI commands, virtual environments, and source control.

3. The 3-Week Progressive Learning Architecture

Week 1: AI Foundations & Deterministic Agentic Primitives (Days 1–8)

Days 1–8

Establish foundational mastery over LLM mechanics, Python 3.12 typing, Pydantic v2 schema constraints, BPE tokenization, KV cache VRAM sizing, constrained decoding DFA grammars, tool wire protocols, and compound reliability.

Week 1 Capstone (Day 8): Autonomous Problem Solver CLI — Hierarchical Pydantic decomposition, Rich terminal UI, Human-in-the-Loop plan approval, and sandboxed self-healing code executor.

Week 2: Autonomous Loops, Vector RAG & Workflow Engines (Days 9–16)

Days 9–16

Formulate the ReAct loop as a POMDP, build dynamic semantic tool registries, write pure Python Okapi BM25 inverted indexes, engineer Hybrid Reciprocal Rank Fusion (RRF), orchestrate LCEL streaming pipelines, and secure n8n visual automation webhooks with HMAC-SHA256.

Week 2 Capstone (Day 16): Multi-Silo Enterprise Knowledge Agent — Multi-silo retrieval engine uniting ChromaDB corporate policies, SQLite HRIS records, safe math calculations, and citation faithfulness auditing.

Week 3: Multi-Agent Systems, LangGraph & Productionization (Days 17–24)

Days 17–24

Master cyclic StateGraph state machines, SqliteSaver crash persistence, Dec-POMDP multi-agent supervisor/worker swarms, OWASP prompt injection defense, reversible PII sanitization, FastAPI Server-Sent Events (SSE) streaming, and SRE availability testing.

Milestone Project (Day 23): Self-Recovering Distributed Agent Workflow — Distributed Saga pattern with zero-duplicate crash reboot idempotency and Streamlit HITL approval cockpit.
Grand Capstone (Day 24): Cyber-Physical Automotive Diagnostic Assistant — SAE J1979 OBD-II CAN bus PID decoder, ISO 26262 ASIL safety risk gate, and multi-node diagnostic master console.
