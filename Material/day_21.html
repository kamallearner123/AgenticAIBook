21.1. Formal Mechanics of Real-Time Agent Streaming: SSE Protocol & Latency Dynamics

When an agent executes multi-step tool calls, total round-trip time is the sum of prompt processing, vector retrieval, and autoregressive generation:

$$T_{\text{total}} = T_{\text{TTFT}} + \sum_{k=1}^K T_{\text{tool}, k} + (N_{\text{tokens}} - 1) \cdot \text{TPOT}$$

If $T_{\text{total}} = 12.8\text{ seconds}$, a traditional HTTP POST endpoint leaves the client browser hanging with a blank spinner, triggering gateway timeouts (HTTP 504) and user frustration. Under Server-Sent Events (SSE), the server establishes a persistent unidirectional connection with chunked transfer encoding (Transfer-Encoding: chunked) conforming to the W3C EventSource standard:

event: thought
data: {"step": "vector_search", "query": "quarterly revenue 2025"}

event: token
data: {"token": "The"}

event: token
data: {"token": " quarterly"}

event: end
data: {"status": "SUCCESS", "total_tokens": 142}

By streaming intermediate tool events and tokens as they are generated, the user-perceived latency drops from $T_{\text{total}}$ to Time-To-First-Token ($T_{\text{TTFT}} \approx 450\text{ms}$), an order of magnitude improvement in user experience.

21.3. Complete Python Implementation 1: Production FastAPI Backend with SSE Token Streaming

This script sets up a production-ready FastAPI service featuring Pydantic v2 schemas, API key validation, and an asynchronous Server-Sent Events (SSE) streaming endpoint powered by LangGraph's astream_events protocol.

program_21_1_fastapi_sse_server.py 
"""
Program 21.1: Production FastAPI Agent Gateway with SSE Token Streaming
Implements Pydantic v2 validation, API key auth, and asynchronous chunk streaming.
"""

import asyncio
import json
from typing import AsyncGenerator
from fastapi import FastAPI, Header, HTTPException, Depends
from fastapi.responses import StreamingResponse
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field

app = FastAPI(
    title="Enterprise Agent Streaming API",
    version="1.0.0",
    description="High-performance async API gateway for autonomous agent execution."
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

API_KEY_SECRET = "corp-prod-secret-9941"

def authenticate_client(x_api_key: str = Header(...)) -> str:
    if x_api_key != API_KEY_SECRET:
        raise HTTPException(status_code=401, detail="Unauthorized: Invalid API Key")
    return x_api_key

class AgentExecutionRequest(BaseModel):
    query: str = Field(..., example="Analyze quarterly gross margins across APAC region.")
    session_id: str = Field(..., example="sess_apac_01")
    temperature: float = Field(0.0, ge=0.0, le=1.0)

async def simulate_agent_event_stream(query: str) -> AsyncGenerator[str, None]:
    """
    Simulates LangGraph astream_events(version='v2') yielding SSE data blocks.
    In production, replace with: async for event in app.astream_events(payload, ...):
    """
    # Step 1: Emit Thought / Tool Event
    yield f"event: thought\ndata: {json.dumps({'status': 'SEARCHING_VECTOR_DB', 'details': f'Querying index for: {query}'})}\n\n"
    await asyncio.sleep(0.4)
    
    # Step 2: Emit Tool Execution
    yield f"event: thought\ndata: {json.dumps({'status': 'TOOL_EXECUTION', 'tool': 'SqlFinanceQuery', 'query': 'SELECT margin FROM apac_sales'})}\n\n"
    await asyncio.sleep(0.5)

    # Step 3: Stream Synthesized Response Tokens
    response_tokens = [
        "Based", " on", " APAC", " financial", " filings,", " gross", " margins",
        " expanded", " to", " 42.8%", " in", " Q3,", " reflecting", " an", " increase",
        " of", " 310", " basis", " points", " YoY."
    ]
    
    for token in response_tokens:
        yield f"event: token\ndata: {json.dumps({'delta': token})}\n\n"
        await asyncio.sleep(0.05)

    # Step 4: Emit Terminal Completion Event
    yield f"event: end\ndata: {json.dumps({'status': 'COMPLETE', 'tokens_emitted': len(response_tokens)})}\n\n"

@app.post("/api/v1/agent/stream", tags=["Streaming"])
async def stream_agent_execution(
    request: AgentExecutionRequest,
    auth: str = Depends(authenticate_client)
):
    """Endpoint serving real-time Server-Sent Events to web and mobile clients."""
    return StreamingResponse(
        simulate_agent_event_stream(request.query),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
            "X-Accel-Buffering": "no" # Prevents NGINX reverse proxy buffer delays
        }
    )

@app.get("/health", tags=["Telemetry"])
async def health():
    return {"status": "HEALTHY", "tier": "API_GATEWAY"}

if __name__ == "__main__":
    import uvicorn
    print("Starting FastAPI Agent Server on http://localhost:8000 ...")
    uvicorn.run(app, host="0.0.0.0", port=8000)

"""
Program 21.2: Streamlit Enterprise Agent Studio with Thought Accordions
Demonstrates multi-turn session chat, collapsible tool execution, and HITL gate.
"""

import time
import streamlit as st

st.set_page_config(page_title="Enterprise Agent Cockpit", page_icon="⚡", layout="wide")

# Sidebar Configuration Controls
st.sidebar.title("🛠️ Agent Configurations")
model_name = st.sidebar.selectbox("Model Provider", ["gpt-4o", "gpt-4o-mini", "claude-3-5-sonnet"])
temperature = st.sidebar.slider("Temperature", 0.0, 1.0, 0.2, 0.05)
enable_db_write = st.sidebar.checkbox("Allow Database Writes (Requires HITL)", value=True)

if "chat_history" not in st.session_state:
    st.session_state.chat_history = [
        {"role": "assistant", "content": "Welcome to the Enterprise Agent Cockpit. How can I assist your team today?"}
    ]

if "pending_approval" not in st.session_state:
    st.session_state.pending_approval = None

st.title("⚡ Enterprise Autonomous Agent Cockpit")
st.caption("Connected to LangGraph Pregel Engine | Persistent SQLite Checkpointer Active")

# Render Past Conversation
for message in st.session_state.chat_history:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# Render Pending Human Approval Box if active
if st.session_state.pending_approval:
    st.warning("⚠️ High-Impact Operation Pending Human Sign-Off")
    action_info = st.session_state.pending_approval
    st.markdown(f"**Proposed Action:** `{action_info['action']}`")
    st.markdown(f"**Target System:** `{action_info['target']}`")
    
    col1, col2 = st.columns(2)
    with col1:
        if st.button("✅ Approve & Dispatch", use_container_width=True):
            st.success("Action approved by operator. Resuming graph execution...")
            st.session_state.chat_history.append({
                "role": "assistant",
                "content": f"Action committed: `{action_info['action']}` executed successfully."
            })
            st.session_state.pending_approval = None
            st.rerun()
    with col2:
        if st.button("❌ Reject & Abort", use_container_width=True):
            st.error("Action aborted by operator. Graph state rolled back.")
            st.session_state.chat_history.append({
                "role": "assistant",
                "content": f"Operation aborted: Operator rejected `{action_info['action']}`."
            })
            st.session_state.pending_approval = None
            st.rerun()

# User Input Processing
if prompt := st.chat_input("Enter instruction or business query..."):
    st.session_state.chat_history.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    with st.chat_message("assistant"):
        # Collapsible Reasoning Accordion
        with st.status("Agent Reasoning & Tool Orchestration...", expanded=True) as status_box:
            st.write("🔍 **Step 1: Security Triage & Input Guardrail**")
            time.sleep(0.3)
            st.write("📂 **Step 2: Vector Similarity Search across Company KB**")
            time.sleep(0.4)
            
            # Check for destructive command trigger
            if "delete" in prompt.lower() or "drop" in prompt.lower() or "update" in prompt.lower():
                st.write("🛑 **Step 3: High-Risk Action Detected: Halting at Interrupt Gate**")
                status_box.update(label="Halted: Awaiting Human Authorization", state="error")
                st.session_state.pending_approval = {
                    "action": prompt,
                    "target": "Production Postgres Cluster"
                }
                st.rerun()
            else:
                st.write("✍️ **Step 3: Formulating Verified Final Response**")
                time.sleep(0.3)
                status_box.update(label="Reasoning Complete!", state="complete", expanded=False)

        # Output final synthesized answer
        answer = f"Synthesized response for instruction: '{prompt}' using {model_name} (Temp: {temperature}). All guardrails verified."
        st.markdown(answer)
        st.session_state.chat_history.append({"role": "assistant", "content": answer})

21.5. Complete Python Implementation 3: SSE Streaming Client with Disconnect Handling

An enterprise backend must be validated by a robust client script. Program 21.3 implements a streaming consumer in Python that parses SSE event blocks and handles graceful connection drops.

program_21_3_sse_client_consumer.py 
"""
Program 21.3: Asynchronous SSE Client Consumer with Telemetry & Disconnect Guard
Connects to FastAPI SSE endpoints and reconstructs streaming tokens and events.
"""

import asyncio
import json
import httpx

API_URL = "http://localhost:8000/api/v1/agent/stream"
HEADERS = {
    "x-api-key": "corp-prod-secret-9941",
    "Content-Type": "application/json"
}

async def consume_agent_stream(query: str):
    payload = {
        "query": query,
        "session_id": "client_sess_501",
        "temperature": 0.0
    }
    
    print(f"Connecting to Agent SSE Stream at {API_URL}...")
    start_time = asyncio.get_event_loop().time()
    first_token_time = None
    token_count = 0
    
    async with httpx.AsyncClient(timeout=30.0) as client:
        try:
            async with client.stream("POST", API_URL, json=payload, headers=HEADERS) as response:
                if response.status_code != 200:
                    print(f"Error: Server returned status {response.status_code}")
                    return
                
                print("Stream Connected! Receiving events:\n" + "-"*50)
                current_event = None
                
                async for line in response.aiter_lines():
                    if not line:
                        continue
                    
                    if line.startswith("event: "):
                        current_event = line.replace("event: ", "").strip()
                    elif line.startswith("data: "):
                        raw_data = line.replace("data: ", "").strip()
                        data_json = json.loads(raw_data)
                        
                        if current_event == "thought":
                            print(f"  [THOUGHT STEP] {data_json.get('status')} -> {data_json.get('details', '')}")
                        elif current_event == "token":
                            if first_token_time is None:
                                first_token_time = asyncio.get_event_loop().time()
                                ttft = (first_token_time - start_time) * 1000
                                print(f"\n⚡ Time To First Token (TTFT): {ttft:.1f} ms\n--- STREAMED OUTPUT ---")
                            
                            delta = data_json.get("delta", "")
                            print(delta, end="", flush=True)
                            token_count += 1
                        elif current_event == "end":
                            total_time = (asyncio.get_event_loop().time() - start_time)
                            print(f"\n\n--- STREAM COMPLETE ---")
                            print(f"Total Tokens: {token_count} | Duration: {total_time:.2f}s")
                            
        except httpx.ConnectError:
            print("Connection failed: Is the FastAPI server running on localhost:8000?")

if __name__ == "__main__":
    test_query = "What were our top performing automotive parts in Q2?"
    asyncio.run(consume_agent_stream(test_query))

21.6. Production Failure Modes & Operational Gotchas

Gotcha 1: Zombie LLM Generation on Client Disconnect

The Failure: A user submits a query, but closes their browser tab after 2 seconds. The client socket disconnects, but the FastAPI backend continues executing costly multi-step LLM calls in the background, consuming hundreds of dollars in unread tokens.

Production Fix: Check await request.is_disconnected() inside the streaming generator loop. If true, immediately break the generator and cancel the downstream LangGraph background task.

Gotcha 2: Streamlit Script Re-Execution Race Conditions

The Failure: Streamlit reruns the entire Python script from line 1 on every user widget interaction. Storing graph instances or unpickled database connections directly in global variables causes re-instantiation on every click, wiping ephemeral caches.

Production Fix: Use st.cache_resource for global stateful objects (LangGraph compiled apps, database connection pools) and st.session_state for user-specific conversation history.

Gotcha 3: Reverse Proxy SSE Buffer Freezes (NGINX / Cloudflare)

The Failure: The FastAPI server streams tokens, but the user sees nothing for 10 seconds, followed by the entire answer arriving in one single burst. Reverse proxies (NGINX, Envoy) buffer HTTP responses by default to optimize packet sizes.

Production Fix: Include the header X-Accel-Buffering: no in FastAPI's StreamingResponse, and configure NGINX with proxy_buffering off; for all streaming agent routes.
