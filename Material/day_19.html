19.1. Formal Foundations: Multi-Agent Decision Processes & Attention Capacity

A multi-agent architecture is formally modeled as a Decentralized Partially Observable Markov Decision Process (Dec-POMDP) or Multi-Agent State Transition System defined as an 8-tuple:

$$\mathcal{M}_{\text{multi}} = \langle \mathcal{I}, \mathcal{S}, \{\mathcal{A}_i\}, \mathcal{T}, \{\mathcal{R}_i\}, \{\Omega_i\}, \{\mathcal{O}_i\}, \gamma \rangle$$
  • $\mathcal{I} = \{1, \dots, M\}$: The finite set of $M$ specialized agents (e.g. Supervisor, Researcher, Coder, QA Auditor).
  • $\{\mathcal{A}_i\}$: Agent $i$'s isolated action space (its dedicated, role-specific tools). For example, Coder only has access to a sandboxed Python REPL; Researcher only has access to vector databases and web scrapers.
  • $\{\Omega_i\}$ and $\{\mathcal{O}_i\}$: Observation spaces and observation probability functions. Crucially, agent $i$ does not see the raw global context of all other agents; it observes only its localized prompt and task input.

The Mathematical Argument for Specialization vs. Monolithic Context

Let $K$ be the number of tools and $L_{\text{tool}}$ be the average token size of a JSON tool definition schema. In a monolithic agent, every inference call carries token overhead:

$$\text{Overhead}_{\text{mono}} = \sum_{k=1}^K L_{\text{tool}, k} \approx K \cdot \bar{L}_{\text{tool}}$$

When $K = 35$ and $\bar{L}_{\text{tool}} = 250$ tokens, the prompt baseline consumes 8,750 tokens before the user query is even read. In contrast, under a Hierarchical Supervisor topology with $M$ agents where each worker has $K_i \approx 3$ tools:

$$\text{Overhead}_{\text{worker}} = K_i \cdot \bar{L}_{\text{tool}} \approx 750 \text{ tokens (91.4\% reduction)}$$

Furthermore, because Transformer self-attention computes an $N \times N$ attention matrix with complexity $\mathcal{O}(N^2)$, decomposing a monolithic context of length $N$ into $M$ independent sub-contexts of size $N/M$ decreases peak quadratic attention compute by a factor of $M$:

$$\text{Compute Ratio} = \frac{M \times (N/M)^2}{N^2} = \frac{1}{M}$$

19.3. Complete Python Implementation 1: Deterministic Hierarchical Supervisor Pattern

The following self-contained program implements a complete Supervisor pattern. A centralized routing node assesses the evolving state and dispatches sub-tasks to dedicated specialist nodes (Researcher, Coder, Reviewer). When the QA Reviewer passes quality gates, the supervisor routes to END.

program_19_1_supervisor_orchestrator.py 
"""
Program 19.1: Deterministic Hierarchical Supervisor Multi-Agent System
Features dynamic routing, specialist workers, and quality-gate termination.
"""

from typing import TypedDict, Annotated, List, Dict, Any, Literal
import operator
from langgraph.graph import StateGraph, END

# 1. Global Multi-Agent State Schema
class MultiAgentTeamState(TypedDict):
    task: str
    research_notes: str
    code_solution: str
    review_verdict: str
    review_comments: Annotated[List[str], operator.add]
    iteration_count: int
    max_iterations: int
    active_worker: str
    final_output: str

# 2. Worker Node: Technical Researcher
def researcher_node(state: MultiAgentTeamState) -> Dict[str, Any]:
    print("\n[RESEARCHER WORKER] Gathering algorithms and mathematical constraints...")
    # Specialist output (simulated domain retrieval)
    notes = (
        "Specification: Compound Interest Formula is A = P(1 + r/n)^(nt).\n"
        "Requirements: P > 0, r in [0.0, 1.0], n >= 1, t >= 0. Must return rounded float."
    )
    return {
        "research_notes": notes,
        "active_worker": "researcher"
    }

# 3. Worker Node: Software Engineer (Coder)
def coder_node(state: MultiAgentTeamState) -> Dict[str, Any]:
    iter_num = state.get("iteration_count", 0) + 1
    feedback = state.get("review_comments", [])
    print(f"\n[CODER WORKER] Drafting Python implementation (Iteration #{iter_num})...")
    
    if iter_num == 1:
        # Deliberate flaw on draft 1: Missing input type guards
        code = (
            "def compound_interest(p, r, t, n=12):\n"
            "    return p * ((1 + (r / n)) ** (n * t))"
        )
    else:
        # Hardened production code incorporating reviewer critique
        code = (
            "def compound_interest(p: float, r: float, t: float, n: int = 12) -> float:\n"
            "    if p < 0 or r < 0 or t < 0 or n <= 0:\n"
            "        raise ValueError('Financial parameters must be non-negative; compounding frequency must be positive.')\n"
            "    return round(float(p * ((1.0 + (r / n)) ** (n * t))), 2)"
        )
        
    return {
        "code_solution": code,
        "iteration_count": iter_num,
        "active_worker": "coder"
    }

# 4. Worker Node: QA & Security Reviewer
def reviewer_node(state: MultiAgentTeamState) -> Dict[str, Any]:
    code = state["code_solution"]
    iter_num = state["iteration_count"]
    print(f"\n[QA REVIEWER WORKER] Auditing code draft #{iter_num} against security and typing standards...")
    
    if "raise ValueError" not in code or "round(" not in code:
        comment = f"Draft #{iter_num} rejected: Missing boundary validation and precision rounding."
        print(f"  ✗ {comment}")
        return {
            "review_verdict": "REJECTED",
            "review_comments": [comment],
            "active_worker": "reviewer"
        }

    print("  ✓ Draft approved: Type hints, boundary guards, and monetary rounding verified.")
    return {
        "review_verdict": "APPROVED",
        "review_comments": [f"Draft #{iter_num} approved for production release."],
        "active_worker": "reviewer"
    }

# 5. Supervisor Routing Logic
def supervisor_router(state: MultiAgentTeamState) -> Literal["researcher", "coder", "reviewer", "finalize"]:
    # Step 1: Research if not done
    if not state.get("research_notes"):
        print("[SUPERVISOR ROUTER] Decision -> Assigning task to RESEARCHER.")
        return "researcher"
        
    # Step 2: Code if not yet drafted
    if not state.get("code_solution"):
        print("[SUPERVISOR ROUTER] Decision -> Assigning task to CODER.")
        return "coder"
        
    # Step 3: Review if pending
    if state.get("active_worker") == "coder":
        print("[SUPERVISOR ROUTER] Decision -> Code updated; routing to QA REVIEWER.")
        return "reviewer"
        
    # Step 4: Evaluate review verdict
    if state.get("review_verdict") == "APPROVED":
        print("[SUPERVISOR ROUTER] Decision -> Code APPROVED. Routing to FINALIZE.")
        return "finalize"
        
    # Step 5: Check retry bounds
    if state.get("iteration_count", 0) >= state.get("max_iterations", 3):
        print("[SUPERVISOR ROUTER] Decision -> Max retries reached. Forcing FINALIZE with escalation.")
        return "finalize"
        
    print("[SUPERVISOR ROUTER] Decision -> Critique feedback pending; routing back to CODER.")
    return "coder"

def finalize_node(state: MultiAgentTeamState) -> Dict[str, Any]:
    print("\n[FINALIZE NODE] Compiling final project package.")
    summary = (
        f"Task: {state['task']}\n"
        f"Final Verdict: {state['review_verdict']}\n"
        f"Total Cycles: {state['iteration_count']}\n"
        f"Verified Code:\n{state['code_solution']}"
    )
    return {"final_output": summary}

# 6. Construct StateGraph
def build_multi_agent_system():
    workflow = StateGraph(MultiAgentTeamState)
    
    # Register Nodes
    workflow.add_node("researcher", researcher_node)
    workflow.add_node("coder", coder_node)
    workflow.add_node("reviewer", reviewer_node)
    workflow.add_node("finalize", finalize_node)
    
    # Entry Point routes to supervisor logic immediately
    # We use a dummy entry or conditional start
    workflow.set_conditional_entry_point(
        supervisor_router,
        {
            "researcher": "researcher",
            "coder": "coder",
            "reviewer": "reviewer",
            "finalize": "finalize"
        }
    )
    
    # Every worker reports back to the supervisor conditional routing
    workflow.add_conditional_edges("researcher", supervisor_router)
    workflow.add_conditional_edges("coder", supervisor_router)
    workflow.add_conditional_edges("reviewer", supervisor_router)
    
    workflow.add_edge("finalize", END)
    
    return workflow.compile()

if __name__ == "__main__":
    app = build_multi_agent_system()
    
    initial_mission: MultiAgentTeamState = {
        "task": "Develop a compound interest calculation module with monthly compounding.",
        "research_notes": "",
        "code_solution": "",
        "review_verdict": "",
        "review_comments": [],
        "iteration_count": 0,
        "max_iterations": 3,
        "active_worker": "",
        "final_output": ""
    }
    
    print("==================================================")
    print("STARTING HIERARCHICAL MULTI-AGENT EXECUTION")
    print("==================================================")
    result = app.invoke(initial_mission)
    
    print("\n" + "="*50)
    print("MULTI-AGENT MISSION COMPLETE")
    print("="*50)
    print(result["final_output"])
    print("\nAudit Trail of QA Review Feedback:")
    for comment in result["review_comments"]:
        print(f"  • {comment}")

19.4. Complete Python Implementation 2: Subgraph Composition & Hierarchical Delegation

In enterprise architectures, teams of agents are often organized as Subgraphs. A parent orchestrator delegates a sub-problem to an independent subgraph that executes its own private cycle, returning only a consolidated summary to the parent state.

program_19_2_subgraph_delegation.py 
"""
Program 19.2: Hierarchical Subgraph Delegation in LangGraph
Parent graph delegates complex analytical sub-problems to an encapsulated child subgraph.
"""

from typing import TypedDict, Dict, Any
from langgraph.graph import StateGraph, END

# --- Child Subgraph: Financial Risk Engine ---
class RiskAnalysisSubState(TypedDict):
    raw_balance: float
    credit_score: int
    computed_risk_score: float
    risk_tier: str

def compute_risk_node(state: RiskAnalysisSubState) -> Dict[str, Any]:
    score = (state["raw_balance"] * 0.001) + (state["credit_score"] * 0.8)
    print(f"    [SUBGRAPH: Risk Engine] Calculated numeric risk score: {score:.2f}")
    return {"computed_risk_score": score}

def categorize_tier_node(state: RiskAnalysisSubState) -> Dict[str, Any]:
    score = state["computed_risk_score"]
    tier = "LOW_RISK" if score > 600 else "ELEVATED_RISK"
    print(f"    [SUBGRAPH: Risk Engine] Assigned classification tier: {tier}")
    return {"risk_tier": tier}

def build_risk_subgraph():
    sub = StateGraph(RiskAnalysisSubState)
    sub.add_node("compute_score", compute_risk_node)
    sub.add_node("categorize", categorize_tier_node)
    sub.set_entry_point("compute_score")
    sub.add_edge("compute_score", "categorize")
    sub.add_edge("categorize", END)
    return sub.compile()

# --- Parent Orchestrator Graph ---
class ParentAccountState(TypedDict):
    account_id: str
    balance: float
    credit_score: int
    risk_assessment: str
    action_taken: str

def intake_node(state: ParentAccountState) -> Dict[str, Any]:
    print(f"\n[PARENT GRAPH] Ingesting loan request for Account: {state['account_id']}")
    return {}

def risk_subgraph_wrapper_node(state: ParentAccountState) -> Dict[str, Any]:
    print("[PARENT GRAPH] Delegating risk computation to Child Subgraph...")
    child_graph = build_risk_subgraph()
    
    # Map parent state channels into child subgraph input schema
    child_input: RiskAnalysisSubState = {
        "raw_balance": state["balance"],
        "credit_score": state["credit_score"],
        "computed_risk_score": 0.0,
        "risk_tier": ""
    }
    
    child_result = child_graph.invoke(child_input)
    print(f"[PARENT GRAPH] Child Subgraph returned verdict: {child_result['risk_tier']}")
    
    # Map child output back to parent schema
    return {"risk_assessment": child_result["risk_tier"]}

def decision_node(state: ParentAccountState) -> Dict[str, Any]:
    assessment = state["risk_assessment"]
    action = "APPROVE_CREDIT_LINE" if assessment == "LOW_RISK" else "REQUIRE_COLLATERAL"
    print(f"[PARENT GRAPH] Final Business Decision: {action}")
    return {"action_taken": action}

def build_hierarchical_parent_graph():
    parent = StateGraph(ParentAccountState)
    parent.add_node("intake", intake_node)
    parent.add_node("risk_engine_subgraph", risk_subgraph_wrapper_node)
    parent.add_node("decision_node", decision_node)
    
    parent.set_entry_point("intake")
    parent.add_edge("intake", "risk_engine_subgraph")
    parent.add_edge("risk_engine_subgraph", "decision_node")
    parent.add_edge("decision_node", END)
    
    return parent.compile()

if __name__ == "__main__":
    system = build_hierarchical_parent_graph()
    
    customer_payload: ParentAccountState = {
        "account_id": "ACC-99214",
        "balance": 150000.0,
        "credit_score": 740,
        "risk_assessment": "",
        "action_taken": ""
    }
    
    print("=== EXECUTING HIERARCHICAL SUBGRAPH ORCHESTRATION ===")
    final_output = system.invoke(customer_payload)
    print("\nFinal Consolidated State:")
    print(f"Account: {final_output['account_id']}")
    print(f"Risk Rating: {final_output['risk_assessment']}")
    print(f"Action: {final_output['action_taken']}")

19.5. Complete Python Implementation 3: Peer-to-Peer Swarm with Deadlock Prevention

When agents interact peer-to-peer (without a central supervisor), circular handoffs can cause infinite loops (Deadlock). Program 19.3 implements dynamic handoff tools and a strict Coffman cycle breaker.

program_19_3_peer_swarm_deadlock.py 
"""
Program 19.3: Peer-to-Peer Agent Swarm with Cycle-Breaking Deadlock Guard
Implements dynamic agent handoffs with bounded transition telemetry.
"""

from typing import TypedDict, Annotated, List, Dict, Any, Literal
import operator
from langgraph.graph import StateGraph, END

class SwarmState(TypedDict):
    customer_message: str
    handoff_history: Annotated[List[str], operator.add]
    transition_count: int
    max_allowed_handoffs: int
    current_agent: str
    resolution: str

def triage_agent_node(state: SwarmState) -> Dict[str, Any]:
    msg = state["customer_message"].lower()
    count = state.get("transition_count", 0) + 1
    print(f"\n[TRIAGE AGENT] Ingesting inquiry (Handoff #{count})...")
    
    if "charge" in msg or "refund" in msg or "invoice" in msg:
        next_target = "billing_agent"
    elif "password" in msg or "login" in msg:
        next_target = "auth_agent"
    else:
        return {
            "current_agent": "triage_agent",
            "resolution": "Resolved directly by Triage with general FAQ.",
            "transition_count": count,
            "handoff_history": ["Triage -> Solved"]
        }

    return {
        "current_agent": next_target,
        "transition_count": count,
        "handoff_history": [f"Triage -> {next_target}"]
    }

def billing_agent_node(state: SwarmState) -> Dict[str, Any]:
    count = state["transition_count"] + 1
    print(f"\n[BILLING AGENT] Processing billing inquiry (Handoff #{count})...")
    
    # Simulate an ambiguous case that needs identity verification
    if "suspicious" in state["customer_message"].lower():
        print("  -> Billing detected potential fraud; handing off to Auth specialist...")
        return {
            "current_agent": "auth_agent",
            "transition_count": count,
            "handoff_history": ["Billing -> Auth"]
        }
        
    return {
        "current_agent": "billing_agent",
        "resolution": "Billing adjustment of $49.00 credited successfully.",
        "transition_count": count,
        "handoff_history": ["Billing -> Solved"]
    }

def auth_agent_node(state: SwarmState) -> Dict[str, Any]:
    count = state["transition_count"] + 1
    print(f"\n[AUTH AGENT] Processing identity verification (Handoff #{count})...")
    return {
        "current_agent": "auth_agent",
        "resolution": "Identity 2FA token verified. Reset link dispatched.",
        "transition_count": count,
        "handoff_history": ["Auth -> Solved"]
    }

def circuit_breaker_node(state: SwarmState) -> Dict[str, Any]:
    print("\n🚨 [CIRCUIT BREAKER] Deadlock detected! Max handoff threshold exceeded.")
    return {
        "resolution": "ESCALATED_TO_HUMAN_TIER3: Automated handoffs exceeded limit."
    }

# Swarm Dynamic Router
def swarm_router(state: SwarmState) -> Literal["triage_agent", "billing_agent", "auth_agent", "circuit_breaker", "finalize"]:
    if state.get("resolution"):
        return "finalize"
        
    if state.get("transition_count", 0) >= state.get("max_allowed_handoffs", 4):
        return "circuit_breaker"
        
    target = state.get("current_agent", "triage_agent")
    return target

def build_swarm_graph():
    swarm = StateGraph(SwarmState)
    
    swarm.add_node("triage_agent", triage_agent_node)
    swarm.add_node("billing_agent", billing_agent_node)
    swarm.add_node("auth_agent", auth_agent_node)
    swarm.add_node("circuit_breaker", circuit_breaker_node)
    
    swarm.set_entry_point("triage_agent")
    
    swarm.add_conditional_edges("triage_agent", swarm_router, {
        "billing_agent": "billing_agent",
        "auth_agent": "auth_agent",
        "circuit_breaker": "circuit_breaker",
        "finalize": END
    })
    
    swarm.add_conditional_edges("billing_agent", swarm_router, {
        "auth_agent": "auth_agent",
        "triage_agent": "triage_agent",
        "circuit_breaker": "circuit_breaker",
        "finalize": END
    })
    
    swarm.add_conditional_edges("auth_agent", swarm_router, {
        "billing_agent": "billing_agent",
        "circuit_breaker": "circuit_breaker",
        "finalize": END
    })
    
    swarm.add_edge("circuit_breaker", END)
    
    return swarm.compile()

if __name__ == "__main__":
    app = build_swarm_graph()
    
    test_ticket: SwarmState = {
        "customer_message": "There is a suspicious charge on my invoice and I cannot login.",
        "handoff_history": [],
        "transition_count": 0,
        "max_allowed_handoffs": 4,
        "current_agent": "triage_agent",
        "resolution": ""
    }
    
    print("=== EXECUTING PEER SWARM WITH HANDOFFS ===")
    verdict = app.invoke(test_ticket)
    
    print("\n" + "="*50)
    print("SWARM EXECUTION TERMINATED")
    print(f"Final Resolution: {verdict['resolution']}")
    print(f"Total Handoff Transitions: {verdict['transition_count']}")
    print("Handoff Trajectory Path:")
    for step in verdict["handoff_history"]:
        print(f"  -> {step}")
    print("="*50)

19.6. Production Failure Modes & Architectural Anti-Patterns

Anti-Pattern 1: Ping-Pong Critique Loops

The Failure: In a Coder ↔ Reviewer pair, the reviewer provides vague critiques ("Optimize this further"), causing the coder to rewrite small cosmetic aspects, triggering another vague review indefinitely. The agents loop back and forth until the budget is depleted.

Production Fix: Require structured critique schemas using Pydantic (e.g. has_syntax_error: bool, failing_unit_tests: list[str]). Enforce a strict iteration ceiling (e.g. max_iterations = 3) after which the system escalates to human review.

Anti-Pattern 2: Information Bottlenecking in Hierarchical Summarization

The Failure: A supervisor delegates tasks to workers but compresses worker results too aggressively before passing context to downstream specialists. The Coder loses vital mathematical nuances discovered by the Researcher because the Supervisor summarized 2,000 words into two sentences.

Production Fix: Use dedicated shared state channels (e.g., research_specifications: str) that pass raw outputs verbatim between dependent workers while using the supervisor strictly for routing control flow.

Anti-Pattern 3: State Contamination via Shared Additive Reducers

The Failure: Multiple concurrent workers append raw scratchpad logs to a single global messages list using operator.add. Messages become interleaved out of chronological order, confusing the model's in-context reasoning.

Production Fix: Isolate worker scratchpads into role-specific state keys (e.g. coder_logs: list[str], reviewer_logs: list[str]) or encapsulate workers within Subgraphs that maintain private local states.
