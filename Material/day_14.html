2. Cryptographic Webhook Security: HMAC-SHA256 & Replay Protection

Vulnerability: Denial-of-Wallet & Replay Attacks

Exposing an unauthenticated webhook endpoint connected to an LLM is a catastrophic financial vulnerability. Malicious bots or port scanners can flood the URL with 50,000 requests, burning your entire OpenAI credit balance in minutes.

The HMAC-SHA256 Signature Contract

To secure inter-service webhooks between Python and n8n, every HTTP request must include an HMAC-SHA256 cryptographic signature and a UNIX timestamp header:

\text{Signature} = \text{HMAC-SHA256}\Big(K_{\text{secret}}, \; T_{\text{timestamp}} \mathbin{\Vert} \text{RawBody}\Big)

The receiver enforces two mandatory security gates:

  • 1. Replay Window Verification: $|T_{\text{current}} - T_{\text{header}}| \le 300\text{ seconds}$. Requests older than 5 minutes are rejected immediately.
  • 2. Constant-Time Digest Comparison: To eliminate side-channel timing attacks, compare digests using hmac.compare_digest() rather than standard string equality ==.

4. Program 2: Production Python FastAPI Webhook Receiver with HMAC Security

When n8n or an external SaaS webhook triggers your Python service, you must verify the cryptographic signature and timestamp to prevent replay attacks:

program_14_2_fastapi_hmac_receiver.py 

# Program 14.0-2: Production FastAPI Webhook Receiver with HMAC-SHA256 Verification
import hmac
import hashlib
import time
from fastapi import FastAPI, Request, HTTPException, Header, status

app = FastAPI(title="Secure n8n Agent Webhook Receiver")
SHARED_SECRET = "enterprise_secret_key_prod_2026"
MAX_TIME_DRIFT_SECONDS = 300  # 5-minute replay attack window

def verify_hmac_signature(payload_bytes: bytes, received_signature: str, timestamp_str: str) -> bool:
    """Verifies HMAC-SHA256 signature using constant-time comparison."""
    if not received_signature or not timestamp_str:
        return False

    try:
        req_time = int(timestamp_str)
        curr_time = int(time.time())
        # Replay attack guard
        if abs(curr_time - req_time) > MAX_TIME_DRIFT_SECONDS:
            print(f"[SECURITY ALERT] Timestamp drift exceeded: {abs(curr_time - req_time)}s")
            return False
    except ValueError:
        return False

    message = f"{timestamp_str}.".encode("utf-8") + payload_bytes
    expected_sig = hmac.new(SHARED_SECRET.encode("utf-8"), message, hashlib.sha256).hexdigest()
    
    # Constant-time comparison prevents timing attacks
    return hmac.compare_digest(expected_sig, received_signature)

@app.post("/webhook/inbound-agent-event", status_code=status.HTTP_202_ACCEPTED)
async def handle_incoming_webhook(
    request: Request,
    x_webhook_signature: str = Header(None),
    x_webhook_timestamp: str = Header(None)
):
    raw_body = await request.body()
    
    # Cryptographic verification
    is_valid = verify_hmac_signature(raw_body, x_webhook_signature, x_webhook_timestamp)
    if not is_valid:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Cryptographic signature verification failed or replay window expired."
        )

    json_payload = await request.json()
    print(f"✓ Verified Webhook Ingested: Event={json_payload.get('event_type')}")
    
    # Return 202 Accepted immediately; process AI pipeline asynchronously
    return {"status": "accepted", "message": "Event queued for asynchronous agent processing."}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)

5. Program 3: Resilient Python-to-n8n Bridge with Dead-Letter Queue (DLQ)

When dispatching events from Python to n8n, network glitches or container restarts must not drop customer events. The bridge below implements exponential backoff retries with full jitter and a persistent Dead-Letter Queue (DLQ):

program_14_3_resilient_webhook_bridge.py 

# Program 14.0-3: Resilient Python-to-n8n Webhook Bridge with Retry & Dead-Letter Queue
import hmac
import hashlib
import json
import time
import random
from typing import Dict, Any
import requests

SHARED_SECRET = "enterprise_secret_key_prod_2026"
N8N_TARGET_URL = "http://127.0.0.1:5678/webhook/ev-telemetry-triage"
DLQ_FILE_PATH = "dead_letter_queue.jsonl"

def sign_payload(payload_dict: Dict[str, Any]) -> Tuple[bytes, str, str]:
    payload_bytes = json.dumps(payload_dict, sort_keys=True).encode("utf-8")
    timestamp = str(int(time.time()))
    msg = f"{timestamp}.".encode("utf-8") + payload_bytes
    sig = hmac.new(SHARED_SECRET.encode("utf-8"), msg, hashlib.sha256).hexdigest()
    return payload_bytes, sig, timestamp

def write_to_dlq(payload: Dict[str, Any], reason: str):
    """Appends undelivered events to Dead-Letter Queue for audit reconciliation."""
    entry = {"timestamp": time.time(), "reason": reason, "payload": payload}
    with open(DLQ_FILE_PATH, "a") as f:
        f.write(json.dumps(entry) + "\n")
    print(f"  [DLQ PERSISTED] Event written to {DLQ_FILE_PATH}")

def dispatch_event_with_resilience(payload: Dict[str, Any], max_attempts: int = 3) -> bool:
    payload_bytes, sig, ts = sign_payload(payload)
    headers = {
        "Content-Type": "application/json",
        "X-Webhook-Signature": sig,
        "X-Webhook-Timestamp": ts
    }

    base_backoff = 0.5
    for attempt in range(1, max_attempts + 1):
        try:
            print(f"--> [Attempt {attempt}/{max_attempts}] Dispatching webhook to n8n...")
            # Simulate network post with 2s timeout
            # resp = requests.post(N8N_TARGET_URL, data=payload_bytes, headers=headers, timeout=2.0)
            # if resp.status_code in [200, 202]: return True
            
            # Simulated transient failure on attempt 1, success on attempt 2
            if attempt == 1:
                raise requests.exceptions.ConnectionError("Connection refused by n8n container.")
            print("    ✓ Webhook accepted by n8n workflow!")
            return True
        except Exception as err:
            jitter = random.uniform(0.1, 0.5)
            sleep_time = (base_backoff * (2 ** (attempt - 1))) + jitter
            print(f"    ✗ Delivery failed ({err}). Retrying in {sleep_time:.2f}s...")
            time.sleep(sleep_time)

    # If all attempts exhausted, write to Dead-Letter Queue
    write_to_dlq(payload, f"Max retries ({max_attempts}) exhausted.")
    return False

if __name__ == "__main__":
    telemetry_event = {
        "event_type": "HIGH_VOLTAGE_FAULT",
        "model": "Tata Nexon EV Max",
        "fault_code": "P0A1F",
        "telemetry": "Battery pack temp 58C, SOC 42%, coolant pressure low."
    }
    dispatch_event_with_resilience(telemetry_event)

6. Production Failure Modes & Engineering Gotchas

  • 1. Webhook Gateway Timeout (504): If an LLM node takes 45 seconds to generate an answer, intermediate reverse proxies (Cloudflare, NGINX) terminate the connection at 30 seconds with an HTTP 504. Mitigation: Configure the webhook node with "Respond Immediately" (HTTP 202 Accepted), running the AI agent asynchronously and sending results via outbound callback.
  • 2. Unauthenticated Public Webhooks: Leaving an open webhook URL without cryptographic signing allows malicious bots to trigger infinite model inferences. Mitigation: Mandate HMAC-SHA256 signatures on all webhooks.
  • 3. SQLite Locking in Self-Hosted n8n: By default, local n8n uses SQLite. Under concurrent load (50+ webhook requests/second), SQLite throws database is locked errors. Mitigation: Configure production n8n with PostgreSQL (DB_TYPE=postgresdb).
  • 4. Uncontrolled Memory Leaks in Large Payloads: Passing high-resolution images or 50MB PDFs through n8n nodes exhausts Docker container RAM. Mitigation: Pass S3 / Cloud Storage presigned URLs instead of raw binary file payloads.
