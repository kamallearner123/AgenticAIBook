16.2. Theory: Groundedness & Faithfulness Verification Metrics

The Faithfulness Mathematical Metric

In legal, healthcare, and enterprise HR applications, answering accurately is not enough: answers must be provably faithful to source text. Let the answer $A$ be decomposed into atomic factual claims $\{c_1, c_2, \dots, c_m\}$. The Faithfulness Score against retrieved context $C$ is:

$$\text{Faithfulness}(A, C) = \frac{\sum_{i=1}^m \mathbb{I}\big(c_i \text{ is directly inferable from } C\big)}{m}$$

where $\mathbb{I}(\cdot) \in \{0, 1\}$ is the indicator function. Production deployment mandates $\text{Faithfulness}(A, C) = 1.0$. If any claim in the response lacks explicit document provenance, the response must be quarantined by the verification gate.

16.3. Program 1: The Complete Company Knowledge Agent Core Engine

The complete implementation below fuses a ChromaDB policy store, an in-memory SQLite HRIS database, a safe arithmetic execution engine, and session window memory into an autonomous agent:

program_16_1_company_knowledge_agent.py 

# Program 16.0-1: Complete Company Knowledge Agent with Multi-Source RAG & Tools
import json
import math
import sqlite3
from typing import List, Dict, Any
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.vectorstores import Chroma
from langchain.agents import Tool, AgentExecutor, create_openai_tools_agent
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain.memory import ConversationBufferWindowMemory

# 1. Models & Vector Store
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0.0)
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

policy_corpus = [
    {
        "content": "Privilege Leave (PL) Encashment Policy: Employees may encash up to 10 days of unused PL at year end. Payout formula: (Basic Monthly Salary / 30) * Eligible Days.",
        "metadata": {"source": "HR Handbook 2026", "section": "Leave Encashment (Sec 5.2)"}
    },
    {
        "content": "Maternity Leave: Female employees receive 26 weeks paid leave for up to two children. Adoptive mothers receive 12 weeks paid leave.",
        "metadata": {"source": "Statutory Benefits Guide", "section": "Maternity Policy (Sec 2.1)"}
    },
    {
        "content": "Broadband Reimbursement: Remote engineers receive up to ₹1,500 INR monthly internet allowance on submitting bill copy.",
        "metadata": {"source": "IT Remote Policy", "section": "Expense Claims (Sec 8.4)"}
    }
]

vectorstore = Chroma.from_texts(
    texts=[d["content"] for d in policy_corpus],
    metadatas=[d["metadata"] for d in policy_corpus],
    embedding=embeddings
)
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# 2. Relational HRIS Database (SQLite)
conn = sqlite3.connect(":memory:")
cursor = conn.cursor()
cursor.execute("""
    CREATE TABLE employees (
        emp_id TEXT PRIMARY KEY,
        name TEXT,
        department TEXT,
        monthly_basic_inr REAL,
        unused_pl_days INTEGER
    )
""")
cursor.execute("INSERT INTO employees VALUES ('EMP-101', 'Ananya Sharma', 'Engineering', 90000.0, 8)")
cursor.execute("INSERT INTO employees VALUES ('EMP-102', 'Vikram Verma', 'Product', 120000.0, 14)")
conn.commit()

# 3. Agent Tool Implementations
def tool_search_policies(query: str) -> str:
    """Search internal enterprise policies, employee handbooks, and benefits rules."""
    docs = retriever.invoke(query)
    if not docs:
        return "No policy documents found matching query."
    results = []
    for d in docs:
        src = d.metadata.get("source", "Handbook")
        sec = d.metadata.get("section", "General")
        results.append(f"[Source: {src}, {sec}]\n{d.page_content}")
    return "\n\n".join(results)

def tool_query_hris(emp_id: str) -> str:
    """Query employee profile, monthly basic salary, and remaining leave days by emp_id."""
    cur = conn.cursor()
    cur.execute("SELECT name, department, monthly_basic_inr, unused_pl_days FROM employees WHERE emp_id = ?", (emp_id.strip(),))
    row = cur.fetchone()
    if row:
        return json.dumps({
            "name": row[0],
            "department": row[1],
            "monthly_basic_inr": row[2],
            "unused_pl_days": row[3]
        })
    return json.dumps({"error": f"Employee ID '{emp_id}' not found in HRIS database."})

def tool_calculate_math(expression: str) -> str:
    """Safely evaluates financial encashment, tax deductions, or arithmetic formulas."""
    try:
        allowed = {"round": round, "abs": abs}
        val = eval(expression, {"__builtins__": None}, allowed)
        return json.dumps({"status": "success", "result": round(float(val), 2)})
    except Exception as e:
        return json.dumps({"status": "error", "message": str(e)})

tools = [
    Tool(
        name="search_company_policies",
        func=tool_search_policies,
        description="Search internal company policies, handbooks, and leave formulas. Always cite source."
    ),
    Tool(
        name="query_employee_hris",
        func=tool_query_hris,
        description="Retrieve confidential employee compensation and leave balances using emp_id (e.g., EMP-101)."
    ),
    Tool(
        name="calculate_math",
        func=tool_calculate_math,
        description="Execute exact arithmetic expressions for leave payouts, taxes, and allowances."
    )
]

# 4. Agent Configuration with Memory
prompt = ChatPromptTemplate.from_messages([
    ("system", (
        "You are the official Company Knowledge Agent. "
        "Strict Operating Rules:\n"
        "1. Every factual statement must cite its exact [Source: Document, Section].\n"
        "2. If an employee queries encashment or benefits, look up their HRIS record, search the policy for formula caps, "
        "and calculate the final payout using the calculate_math tool.\n"
        "3. If a policy is not found in company documentation, explicitly say: 'I could not find this in official company documentation.'\n"
        "4. Be professional, direct, and empathetic."
    )),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad")
])

memory = ConversationBufferWindowMemory(k=3, memory_key="chat_history", return_messages=True)
agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, memory=memory, verbose=True)

if __name__ == "__main__":
    print("=" * 65)
    print("COMPANY KNOWLEDGE AGENT INITIALIZED")
    print("=" * 65)

    test_query = (
        "Check records for employee EMP-102. Can he encash all his unused PL days under company policy, "
        "and what will his total gross payout be in INR?"
    )
    result = agent_executor.invoke({"input": test_query})
    print("\n" + "=" * 25 + " AGENT RESOLUTION " + "=" * 25)
    print(result["output"])
Program 16.0-1: Company Knowledge Agent Core Execution Engine

16.4. Program 2: Automated Faithfulness & Citation Validator

To eliminate legal compliance risks, the validator below inspects the agent's output, checking that every numerical dollar amount and policy clause cited corresponds directly to verified retrieved evidence:

program_16_2_citation_validator.py 

# Program 16.0-2: Production Faithfulness & Citation Verification Gate
from typing import List
from pydantic import BaseModel, Field
from openai import OpenAI

client = OpenAI()

class ClaimAudit(BaseModel):
    claim_text: str
    is_supported: bool
    cited_source_valid: bool
    discrepancy_explanation: str

class VerificationAuditReport(BaseModel):
    all_claims_faithful: bool
    faithfulness_score: float = Field(ge=0.0, le=1.0)
    audited_claims: List[ClaimAudit]

def verify_response_faithfulness(agent_response: str, retrieved_context: str) -> VerificationAuditReport:
    """Evaluates whether all claims in the response are grounded in the retrieved context."""
    audit_prompt = f"""
    You are an Enterprise Legal Compliance Inspector.
    Audit the generated agent response against the provided reference context.
    
    RETRIEVED REFERENCE CONTEXT:
    {retrieved_context}
    
    GENERATED AGENT RESPONSE:
    {agent_response}
    
    Deconstruct the response into individual factual claims and check if each claim is directly supported.
    """
    comp = client.beta.chat.completions.parse(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": audit_prompt}],
        response_format=VerificationAuditReport,
        temperature=0.0
    )
    return comp.choices[0].message.parsed

if __name__ == "__main__":
    context = "Section 5.2: Maximum leave encashment is 10 days. Rate is (Monthly Basic / 30) * Days. Vikram Verma basic is 120,000 INR."
    valid_response = "Under Section 5.2, Vikram Verma can encash a maximum of 10 days, resulting in a payout of ₹40,000 INR."
    
    audit = verify_response_faithfulness(valid_response, context)
    print(f"Audit Passed: {audit.all_claims_faithful} (Faithfulness: {audit.faithfulness_score:.2f})")
    for claim in audit.audited_claims:
        print(f" - Claim: '{claim.claim_text}' | Supported: {claim.is_supported}")

16.5. Program 3: Multi-Turn Interactive CLI with Session Memory

Below is a terminal user interface allowing employees to conduct ongoing conversational inquiries, maintaining state across questions while streaming tool invocation traces:

program_16_3_interactive_employee_portal.py 

# Program 16.0-3: Multi-Turn Employee Portal CLI with Live Session Memory
import sys
from program_16_1_company_knowledge_agent import agent_executor

def run_interactive_portal():
    print("=" * 60)
    print("Welcome to the Enterprise Employee Knowledge Portal")
    print("Ask any question about company policies, leave, or benefits.")
    print("Type 'exit' or 'quit' to end session.")
    print("=" * 60)

    while True:
        try:
            user_input = input("\nEmployee Question > ").strip()
            if not user_input:
                continue
            if user_input.lower() in ["exit", "quit"]:
                print("Session closed. Goodbye!")
                break

            print("\n--> Agent Processing...")
            result = agent_executor.invoke({"input": user_input})
            print("\n" + "-" * 40)
            print(result["output"])
            print("-" * 40)
        except (KeyboardInterrupt, EOFError):
            print("\nExiting session...")
            break

if __name__ == "__main__":
    run_interactive_portal()

16.6. Production Failure Modes & Hardening Playbooks

  • 1. Cross-Employee Salary Leakage (Data Privilege Violation): If an employee asks: "What is my manager's salary?", an unconstrained agent might query the HRIS database and disclose confidential executive compensation. Hardening: Enforce session identity token authentication in query_employee_hris; only return records matching the authenticated user's emp_id unless an executive role flag is present.
  • 2. Hallucinated Citation Phantom: Models may output realistic-looking citations like [Source: HR Handbook 2024, Sec 9.1] that do not actually exist in the retrieved text. Hardening: Run Program 16.0-2 as a post-generation regex assertion gate to guarantee the cited text string exists verbatim in the retriever output.
  • 3. Stale SQL Ledger Cache: If an employee submits an expense claim in another tab, the agent must not read cached stale balance numbers. Hardening: Ensure database queries run with transactional read-committed isolation and zero local query caching.
  • 4. Arithmetic Hallucination on Edge Cases: If an employee has 14 unused days, but policy caps encashment at 10 days, models without strict guidance may multiply by 14 instead of 10. Hardening: Require the agent to explicitly state the capped days before invoking the calculator tool.
